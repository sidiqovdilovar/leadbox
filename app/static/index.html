Приём заявок

Заявки с сайта — в одном месте

Форма проверяет ввод, сервер хранит заявки, админка показывает их списком. Заголовок на этой странице меняется по A/B-тесту — счётчики видны в статистике.

Одно поле: телефон, name@example.com или @nickname

Заявка принята. Номер: —. Посмотреть её можно в админке.

Данные из формы использую только для ответа на заявку и не передаю третьим лицам.

Что внутри
  • Проверка на сервере. Телефон приводится к +7…, почта и ник проверяются регуляркой, мусор не сохраняется.
  • Защита от спама. Повторная заявка с тем же контактом за сутки не пройдёт, больше пяти в час с одного адреса — тоже.
  • A/B-тест. Посетителю выдаётся вариант A или B, кука закрепляет выбор, конверсия считается по вариантам.
  • UTM-метки. Из адреса страницы сохраняются источник и кампания — видно, откуда пришла заявка.
Стек

FastAPI и SQLite на бэкенде, чистый JavaScript на фронте, pytest для тестов. Запускается в Docker, проверка в CI на каждый коммит.
